# CLAUDE.md — Canteen Gan En

Aplikasi kantin sekolah keluarga. **Kantin ini VEGAN** — seluruh menu nabati/olahan nabati (termasuk menu bernama "ayam", "bakso", dsb — itu mock meat, BUKAN daging asli). Pengguna utama: Mama & Papa (±50–60 th, non-teknis) dan orang tua murid. Live di canteen-gan-en.vercel.app (halaman ortu: /pesan). Stack: React + Supabase + Vercel.

## ATURAN EMAS (baca dulu)

1. **File dari pemilik = pakai APA ADANYA.** Jangan menulis ulang, meringkas, "memperbaiki", atau menambah konten/desain pada file .jsx/.html yang diberikan. Konten sudah final.
2. **Jangan mengarang kebijakan.** Dilarang menambah kalimat aturan/kebijakan apa pun di halaman yang dilihat orang tua (mis. syarat pembatalan, jam layanan) tanpa diminta eksplisit.
3. **Semua halaman/komponen BARU wajib memakai design tokens di bawah.** Jangan pakai styling default/bootstrap-ish/gradien ungu/font sistem.
4. **TIDAK ADA emoji/ikon daging atau seafood di mana pun** (🍗🍤🍖🥩🍣🐟 dsb) — kantin ini vegan. Untuk menu bernama seperti "ayam"/"bakso" (mock meat nabati), pakai ikon netral (mis. 🥘🧆🍚), bukan ikon hewan/daging asli.
5. Keputusan produk lengkap ada di `perintah-perbaikan-claude-code.md` — kalau ragu, rujuk ke sana, jangan menebak.
6. **Panduan wajib satu sumber.** Konten floating help button (?) di PreOrderParent HARUS sama persis dengan `panduan-pemesanan.html` — jangan duplikat/tulis ulang terpisah. Kalau modal butuh render beda (mis. bukan iframe), ambil isinya dari file yang sama, bukan salin-tempel manual yang bisa nyimpang seiring waktu.

- **Warna:**

Papa melihat dengan SATU mata → pemisahan antar kartu harus jelas lewat selisih terang-gelap. Sumber tunggal: `src/lib/theme.ts` (jangan hardcode hex baru).

  - Peringatan: Telat/Ditutup `#A82F24` (bg `#FBE7E3`) · Tutup otomatis jingga `#8F4E08` (bg `#FFE9CC`)
  - Teks `#2A2820` · Teks redup `#5F5C4D` · Border `#E8E0D2` (tipis, seperti versi lama; JANGAN gelap/hitam) · Border tegas `#DDD4C0` · Divider `#F1EBE0` · Garis elemen terpilih `#F2B53C` (kuning madu)

- **Bentuk:** kartu radius 16–18px; tombol radius 12–14px; pil radius 999. Border 1–1.5px, bukan shadow berat.
- **Ukuran:** target sentuh ≥48px; teks penting besar & tebal (pengguna 50–60 th): judul 17–23px w800, isi ≥15px.
- **Ikon:** Lucide saja.
- **Emoji:** DILARANG di UI admin. Pengecualian: tile kategori halaman parent (map tetap di kode) + branding 🪷.
- **Rasa:** kalem ala Apple/Notion/Linear. Satu warna = satu tugas (lihat palet). Bukan dashboard POS ramai, bukan Material warna-warni.
- **Kolom ketik:** huruf WAJIB ≥16px (sudah dipaksa global di `theme.css`) — di bawah itu Safari iOS memperbesar layar dan terasa "susah mengetik".
- **Header halaman (4 tab + halaman baru):** SAMA PERSIS — padding atas 20px, baris `flex items-center justify-between`, judul 22px w800 `letter-spacing:-.02em` rata kiri 20px (hasilnya top ±26px di HP), (tanpa gear — dihapus; baris judul tetap setinggi 44px supaya posisi judul sama di semua tab). Info ringkas (mis. total) boleh di kanan, jangan mengubah tinggi/posisi baris judul. Jangan bikin variasi per halaman. **PENGECUALIAN Pre-order:** TANPA gear (terlalu ramai); di kanan judul hanya saklar ON/OFF berbentuk PIL 46×26 (selaras ukuran huruf judul) (kenop putih berikon Power; bukan bulat), tanpa tulisan: hijau `t.success` = dibuka · merah solid `#D9382A` = ditutup · merah lembut `#FFDDD7` + garis 2px `#E0392B` = tutup otomatis.
- **Tombol melayang "kembali ke atas":** UBIN persegi membulat 48px radius 14, SAMA dengan ubin kalender di Pre-order (isi `t.surface`, garis 1.5px `t.border`, bayangan tipis) + panah gelap, kanan bawah di ATAS nav (bukan menempel dasar). Bukan bulat, bukan hitam, bukan kuning.
- **Pre-order bagian atas: LEGA, tanpa kotak/garis/pil** (mata Mama & Papa sudah tua; "kemepet" dan "banyak border" DITOLAK): judul kiri atas = status ("Pre-order telah dibuka" hijau / "ditutup" merah / "tutup otomatis"); kanan: saklar pil ON/OFF (tanpa gear, tanpa ⋯). Blok tanggal/angka/tombol KEMBALI KE VERSI AWAL (pemilik: "kembalikan 6 border kotak seperti awal"; gaya lega/bulatan/⋯ sudah dicoba dan DITOLAK): SATU bingkai luar (1.5px `t.border`, radius 18, TANPA isi warna — hanya garis) membungkus tanggal + tiga angka + Bagikan/Rekap/Cetak; elemen di dalamnya TANPA border sendiri (ikon kalender polos, tanpa divider; angka aktif = latar kuning pucat; tombol = ikon+teks). Jangan pakai tampilan kalender di semua tempat ("pusing"). Kategori (tetap, disukai pemilik): cari = ikon + kategori = teks polos 16px, terpilih = garis kuning 4px di bawah (menggantikan chip bergaris). Kartu pesanan: ganjil `t.surface` TANPA bingkai, genap `t.bandAlt` `#DBEEB5` + bingkai HIJAU 1.5px `t.bandAltLine` `#A9CE78` (bukan krem/beige; pemisah kepala/daftar di kartu genap juga hijau) (hijau krem agak naik dari #E4EEC9 yang "too muted"; hijau bubble WhatsApp `#D9FDD3` DITOLAK); kartu ganjil bayangan 1px. Lembar Tanggal = kalender bulan (hari berpesanan kuning; DISETUJUI) + "Hari Sekolah Berikutnya"/"Pilih tanggal lain" untuk memindah sesi.
- **Transaksi tab Lunas & Dibatalkan: SATU baris per transaksi** (usul pemilik): ikon status bulat (Lunas = lingkaran hijau berbingkai + latar hijau tipis + centang; Dibatalkan = lingkaran abu dicoret, harga dicoret) · ikon sumber polos (Utensils = Pre-order, ShoppingCart = Penjualan; tanpa kotak kuning) · tanggal · nominal · panah. Isi pesanan & tombol (Belum Dibayar / Batalkan / Hapus, atau Pulihkan / Hapus) HANYA di struk yang terbuka saat baris diketuk. Tanpa pil teks "Lunas"/"Dibatalkan" berulang. **Tab Belum Dibayar (opsi 2 pilihan pemilik):** baris sama (lingkaran putus-putus, ikon sumber, tanggal, nominal, tulisan "Rincian ›"); footer kartu = DUA tombol berlabel sama besar 48px: "Tagih via WA" (berbingkai; jadi hijau "Ditagih dd/mm" setelah dikirim) + "Lunaskan Semua" (kuning). Tombol ikon polos DITOLAK untuk Mama/Papa ("susah ditebak"): selalu beri tulisan. Tandai Lunas / Batalkan per transaksi ada di struk. Baris daftar TIDAK menampilkan "dicatat"; struk tetap memuat Untuk/Dicatat/Sumber/Status.
- **Kolom cari (Pre-order, Penjualan, Transaksi, Menu):** SAMA — tinggi 44px, latar `t.surface` (krem kartu), garis 1.5px `t.border`, sudut 12, huruf 16px (cegah zoom iOS), ikon Search 18px `t.text2`. Tombol + di Menu 44×44. Pil KELAS di mana pun = border saja `#A59B80`, tanpa warna per tingkat (termasuk Transaksi). Tab kertas: satu baris (nowrap).

## KEPUTUSAN PRODUK TERKUNCI (ringkas)

- **Tab Menu: tanggal bawaan otomatis** = tanggal sesi; setelah jam ambil TERAKHIR hari itu lewat (dari jadwal Waktu Ambil, cadangan 13:00) atau tanggal sesi sudah lewat → hari sekolah berikutnya (lewati Sabtu/Minggu). Jangan pindah di jam tutup 08:00 — orang tua kantin masih packing.
- Satu sesi Pre-order aktif; ortu TIDAK pernah memilih tanggal; **Tanggal Layanan ditetapkan server** dari sesi aktif; auto-tutup (default 08:00) ditegakkan server (tolak pesanan).
- Pre-order langsung masuk Transaksi sebagai **Belum Dibayar sejak submit** (packing ≠ tagihan).
- Batalkan transaksi = **soft-delete** (tetap tampil di riwayat Lunas dengan badge).
- Nav 5 tab: Pre-order · Penjualan · Transaksi · Menu · **Kantin** (tab ke-5 = profil + Laporan + pengaturan, satu pintu). TIDAK ADA ikon gear di tab mana pun. Halaman Kantin (usul pemilik): judul "Kantin"; profil (avatar kuning + nama + no HP, pensil soft untuk ubah, TANPA bingkai — dipisah garis tipis); kartu besar **Laporan** (pilihan pemilik C: kuning pucat, angka bulan ini besar, lencana ▲/▼ % dibanding PERIODE YANG SAMA bulan lalu (1–tgl hari ini; bukan seluruh bulan lalu, supaya tidak menyesatkan — berlaku juga di halaman Laporan), batang pembagi Pre-order kuning madu / Penjualan hijau, panah) → membuka Laporan dengan tombol kembali; lalu ubin gaya layar utama iPhone (pilihan pemilik no.1: kotak membulat 76px kuning pucat, nama di bawah, 3 kolom; lencana merah jumlah isi di Tong Sampah) TANPA keterangan: Panduan · Edit Pesanan · Waktu Ambil (Daftar Kelas ada di dalamnya) · Tagihan (kalimat pembuka/penutup WA + rekening) · Printer · Tong Sampah. Bagikan Link tidak di sini (ada di Pre-order); Tentang dihapus. Panduan = `public/panduan-kantin.html` (salinan apa adanya dari `panduan-kantin-gan-en.html`).
- Tingkat dinamis (KB, TK A, TK B, SD, SMP, SMA, Guru/Karyawan) dikelola dari Pengaturan.
- **Waktu Ambil dinamis** (default: "Istirahat 1", "Istirahat 2", "Istirahat 3", "Pulang Sekolah") dikelola dari Pengaturan → tambah/edit/hapus tanpa coding.
